# 方案「书院 · 檐棂印」设计稿

审看反馈现有 UI「不够书香门第、看不出是书院」，这是据此重做的方向稿。

## 怎么看

- **只看效果**：直接开 `shots/` 里的 PNG（375×812，2 倍图，和真机一致）。
- **要看细节/改色**：必须起一个本地服务再开 HTML，`file://` 下字体和素材都会被浏览器挡掉。

```bash
cd design && python3 -m http.server 8898
# 然后访问 http://127.0.0.1:8898/demo/v2/home.html
```

| 文件 | 内容 |
|------|------|
| `home.html` | 主页（主推方向） |
| `login.html` | 登录页 |
| `news-detail.html` | 资讯详情（代表性二级页） |
| `home-indigo.html` | 靛青备选主页，**只换色不换结构**，用于和主推对照 |
| `shuyuan.css` | 全部设计令牌与三件记忆装置的实现 |
| `shots/` | 上面四页的导出图 |

## 三件记忆装置

1. **檐** —— 每一页顶部一道起翘屋檐（瓦垄、檐口金线、瓦当、椽头），二级页矮一半。全站最强的身份标记，纯 SVG，不用一张图。
2. **棂** —— 步步锦格心不是贴花，直接当功能区的底层网格；首图、展馆封面右上角压同一套棂格作层次。
3. **印** —— 朱砂是全站唯一的高饱和色，**取自校方印章本身**，只出现在栏目印、标签、选中态、主按钮。

另有 **瓦当** 作五个功能入口的圆框（联珠纹 + 宋体单字 + 完整中文标签）。

| 素材 | 用法 |

| `brand/logo/extracted/academy-cn-ink.png` | 首页顶部书法字。**用墨色版**——原来首页用的是海军蓝版，落在纸色底上会跳 |

| `brand/logo/school-emblem.png` | 只用在登录页页脚、关于页、海报角标，不当主视觉（圆形 + 英文环，缩小后糊） |

## 还没解决的

- **首图和封面现在是纯色 + 远山剪影**，是占位。校方若能提供实拍图（书院活动、讲座现场、书法作品、图书室），这几块换成照片会明显更厚。
- **图标是几何线描，不是手绘插画**。要再上一个台阶需要插画师，现有这套的定位是「专业、统一、经得起放大」。
