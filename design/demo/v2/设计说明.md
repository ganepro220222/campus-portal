# 中华文化书院 · 视觉方案「书院 · 檐棂印」设计说明

> 本文说明这套界面每一处为什么这样做。所有色值、体积、对比度均取自实现代码实测，不是估算。
> 对应稿件：`design/demo/v2/`（主页 / 登录页 / 资讯详情 / 靛青备选 / 已上传封面图对照）

---

## 一、要解决的问题

甲方的反馈是：现有界面**不是不好看，是看不出这是书院**——不够「书香门第」，一眼留不下印象。

诊断下来，缺的不是装饰，是**主体**。

参照物是故宫博物院小程序。它之所以让人一眼记住，并不在于多精致，而在于**它贴着自己的主体**：紫禁城的建筑、院藏的文物。换句话说，它的视觉就是它自己。

我们的主体是**「中华文化书院」**——一个概念，不是一处建筑。由此定下两条边界：

- **不照搬故宫。** 故宫的识别度来自它自己的藏品与宫殿，借过来只会得到一个"像博物馆的东西"。
- **不迁就校园实景。** 书院是虚拟概念，线下校区是现代建筑，硬去对应只会两头不着。

目标因此很明确：**让人一眼认出「这是书院」，并且耐看。**

---

## 二、方案：三件记忆装置

记忆点必须**少而重复**。堆十种纹样等于没有纹样。整套只立三件，外加几件配角。

### 装置一 · 檐

**为什么是檐。** 讲堂、山门、书院——中式建筑最先被认出来的永远是屋顶。更重要的是，它可以出现在**每一页的同一个位置**。重复即记忆。

**它是由构件拼起来的，不是一条装饰线。** 从上到下：

| 构件 | 作用 |
|------|------|
| 正脊 + 鸱吻 | 屋顶的顶，两端各一只吻 |
| 筒瓦 | 半圆截面的瓦垄，一根根排开 |
| 檐口金线 | 屋面与檐口的分界 |
| 瓦当 | 筒瓦的圆形收头 |
| 滴水 | 板瓦沟里的如意形垂片，与瓦当相间 |
| 檐檩 | 一根圆木梁，把椽头串起来 |
| 椽头 | 露在外面的木方端头 |

**起翘曲线用八次方。** 真屋檐正面看是「中间一条近乎平直的檐口，只在最外两端急促翘起」。二次、三次方会做成整幅下垂的弧——远看就是一块挂着的布。这一版曲线让中间 70% 几乎不动，翘全部集中在最外侧，才是翼角。

**二级页的檐矮一半。** 身份保留，版面不被吃掉。

**瓦是青灰的，不是木色的。** 屋顶本来就不是木头。给瓦自己的黛青色调之后，木构件（椽头、檐檩、枋、匾）才衬得出来，整页也不会一片棕。

### 装置二 · 棂

**用冰裂纹，不用步步锦。** 步步锦是规整的几何，画出来很容易被读成棋盘格或网格纸。冰裂是无规则的，一眼就是中式窗棂或瓷器开片，不会认错。

**它是结构，不是贴花。** 冰裂纹铺在功能入口区的「格心」里，而那一整块被做成一扇**槅扇门**：上下枋（木横档 + 金线）夹着格心，格心四角有角叶。装饰与结构合一，这一点是和市面上「在旁边贴一朵花纹」的中国风拉开距离的地方。

### 装置三 · 印

**朱砂取自校方印章本身。** 所以全站的按钮红、栏目印、选中态、标签，永远是同一个红——不会出现两种红打架。

**它是全站唯一的高饱和色，只出现在小面积。** 大面积永远是纸与墨。

**钤印不能是印得完美的。** 真印章有三个特征，缺一件就成了"贴了张图片"：

1. **歪一点点**——而且左右交替，两枚印不会歪成同一个角度
2. **边缘缺墨**——用噪声遮罩做出零星漏白
3. **深浅不匀**

## 三、配角装置

### 瓦当与小篆

五个功能入口装在同一枚**瓦当**里，当心是**小篆单字**：闻 / 览 / 讲 / 籍 / 集。

瓦当按**文字瓦当**的规制做：外缘、联珠纹、弦纹、界格。汉代瓦当分两路，一路用纹样（莲瓣、云纹）占满当面，一路是文字瓦当（「长乐未央」那种），中间是字、四周是界格——**两者不混**。既然当心要放字，就按文字瓦当来。

小篆字形由校方提供，取自《说文解字》小篆，是**玉箸**一路（笔画粗细均匀、体势端正对称），与这套细线几何完全合拍。字是**阴刻**的——刻在陶上，不是印上去。

### 匾额

「精品好物」做成一方**黑漆金字匾**。书院祠堂的匾本来就是这个规制，比棕木匾大气。金字是**阳刻贴金**，匾面有一道斜掠的漆光。

### 装裱

所有会放封面图的位置，都按**装裱**来做：裱边、包角、压角印、题签。这一套的用意见第六节。

### 祥云

深色块底部压两层祥云，代替常见的波浪。波浪读起来是山水或海浪，都不是书院的词。

一朵祥云 = **一簇大小不一的圆瓣 + 云卷 + 沿上缘的内轮廓双钩**。连续均匀的圆弧带做出来是花边，不是云——真祥云是一团一团断开的，团里还有卷。

## 四、配色

全站颜色分六族，**每一处都从令牌取，不允许写死**。这条由构建期护栏 `check:design-tokens` 强制。

### 纸

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--paper` | `#F2ECDE` | 页面底 |
| `--paper-card` | `#FBF7EF` | 卡片 |
| `--paper-1/2/3` | `#F4EDDD` / `#EDE3CE` / `#E2D5BA` | 签条、凹陷、内嵌 |

### 墨（大面积深色）

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--mo-60` | `#494540` | 首图最亮端 |
| `--mo-70` | `#3A3733` | 首图中段、匾额面 |
| `--mo-80` | `#2E2B28` | 登录页底、匾额深处 |
| `--mo-90` | `#232120` | 最深 |

### 木（色阶 `--wood-05` 至 `--wood-95`）

| 令牌 | 色值 | 色相 / 饱和 / 明度 |
|------|------|------|
| `--wood-30` | `#DCCCB0` | 38° / 39% / 78% |
| `--wood-50`（主色） | `#B9A383` | **36° / 28% / 62%** |
| `--wood-70` | `#7F6E55` | 36° / 20% / 42% |
| `--wood-80` | `#635640` | 38° / 21% / 32% |

### 瓦 / 朱 / 金

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--tile` | `#61696E` | 黛瓦，203° 偏青 |
| `--zhu` | `#A8342A` | 朱砂，全站唯一高饱和色 |
| `--gold` | `#C8A45C` | 细线、描边 |
| `--gold-lit` | `#E6C77C` | 黑漆匾上的金字 |

### 两条关键的配色判断

**① 木色色相钉在 36–38°。**

咖啡与胡桃在 25° 上下，**偏红**——那是老家具的色相。金丝楠、白橡偏黄。这一条就是「老气」与「上档次」的分水岭。

| | 色相 | 观感 |
|---|---|---|
| 最初的 `#6B4A32` | 25.3° | 咖啡 |
| 中途的 `#9A6E48` | 27.8° | 还是咖啡 |
| **现在的 `#B9A383`** | **36.0°** | 浅原木 |

**② 大面积深色用墨，不用棕；木头只做框、线、小件。**

「老气」的完整配方是**深 + 高饱和 + 偏红 + 铺大面**。只调色相不动面积是没用的。这一版四条同时改：明度提上去、饱和度压下来、深色面全部换成墨、木头退回到裱边/枋/包角/椽头这些构件上。

一个旁证：深色面从棕换成墨之后，同一批文字的对比度从 4.13 涨到 8.98——**中深棕本来就是对文字很不友好的底色**，这也从侧面说明它不该铺大面积。

### 展馆分类色

三个馆用**同一个明度层级**，只在色相上各偏一点：墨 / 黛青（`#4C5D68`）/ 苔绿（`#4A5A4C`）。原先那组蓝绿饱和度高出一大截，三张封面摆在一起像来自三个地方。

## 五、材质与光

### 一条总规矩

> **光从上方来。**
> 阴刻（凿进去）＝ 上沿暗、下沿亮。
> 阳刻（凸出来）＝ 上沿亮、下沿暗。

方向一旦反了，立刻就是「贴纸」。这一条是所有立体效果的总开关。

### 五种材质

| 材质 | 用在哪 | 做法 |
|------|--------|------|
| **纸** | 页面、卡片、签条、选中的输入框 | 纤维噪声 + 中亮四周暗的晕 |
| **墨漆** | 首图、匾额、登录页 | 漆面 + 竖纹 + 斜掠漆光 |
| **木** | 裱边、上下枋、包角、椽头 | 三层不同周期的木纹 |
| **石** | 次按钮 | 比纸纤维更高频的颗粒 |
| **陶** | 瓦当 | 径向渐变胎体 + 内高光 + 落影 |

**纹理全部是 CSS 渐变与内联 SVG 噪声，零位图。** 可换色、可主题化、不占包体积——这对小程序的 2MB 主包限制是硬要求。

木纹用**三层不同周期**（5 / 23 / 13）叠加，错开周期才不会看出规则条纹；大面积木面另配一组宽周期年轮再打散一次。

### 状态与反馈

- **输入框未选中** = 凿进漆面的凹槽：不透明底（页面纹理透不过来），内阴影在上沿，底沿一道极细金反光
- **输入框选中** = 整块翻成纸，描边转朱砂。在书院里"输入"就是在纸上写字，这个隐喻比加个蓝框贴切
- **主按钮** = 朱漆块：顶棱高光 + 底棱暗边 + 金圈 + **侧壁**。那道侧壁是"能按下去"的来源
- **次按钮** = 石青块，与页面、与主按钮都不是一种材质
- **按下** = 下沉 1–3px、侧壁收掉。瓦当按下是下沉 + 朱砂一闪，像落了个印

幅度一律很小（1px / 0.6%）——大了就成弹簧。

### 毛边

**只给「一张纸」用**：题签、钤印那方纸。界面里的卡片是印刷品，边就该是齐的。抖幅只有一两个百分点，毛边是纸纤维的断口，不是撕破的口子。

## 六、封面图上传后，设计会不会被盖住

这是最实际的一个问题，答案是**部分会，而且是设计好的**。

| | 结果 |
|---|---|
| **会被盖住** | 画心里的祥云、木纹底——它们本来就在「图的位置」上 |
| **盖不住** | 裱边木纹 · 四角包角 · 右下压角印 · 竖排题签 · 标题绢条 · 题签签条 |

做法是把纹样**一律挪到画心之外，或压在画心之上**：

- **裱边**：木框，永远露在外面
- **包角**：装裱护角，只吃四个角，主体内容一点不挡
- **压角印**：中国画的画心右下角本来就钤印。**它本来就该压在图上**，不存在被覆盖的问题，占地极小却是最强的身份标记
- **题签**：名字写在签条上，图再满也盖不住
- **绢条**：标题落在一条半透明的绢上，同时保证任何照片上文字都读得清

换句话说：**以后每张封面图都会自动带上包角和一枚朱印，看起来就是一张裱好的画。**

对照稿见 `home-cover.html`。

## 七、字

### 正文与标题：内嵌宋体子集

- 字体：**思源宋体 Noto Serif SC**，SIL OFL 1.1，可商用、可嵌入、可子集化
- 子集：**4009 字符**（GB2312 一级 3755 + 项目全语料 + 书法繁体雅字 + 标点），单字重 400
- 体积：woff2 **689 KB** → base64 **919 KB**
- **主包 1530 KB / 2048 KB，余量 518 KB**

**为什么内嵌而不用 `wx.loadFontFace`：** 后者只收网络地址，要配 `downloadFile` 合法域名，还必须返回 `Access-Control-Allow-Origin: *`（设成 `servicewechat.com` 时 iOS 能过、安卓挂），荣耀 / vivo 等机型对字体 CORS 的校验更严——**做不到「所有设备都正常显示」**。内嵌进代码包则不走网络、不需要白名单、没有机型分裂。

`font-family` 回退栈保持完整：字体万一没生效就退回系统字，**不会白屏、不会豆腐块**。

### 入口：小篆字形

校方提供的《说文》小篆 SVG。清洗做了两件事：

1. **剔除水印**——原始文件每个字都夹着两条近白色路径，白底上看不见，落到纸色或深色底上会显形
2. **归一化**——字面统一到 1000×1000、居中占 760，五个字的高度与线宽这才一致

## 八、可访问性

所有前景/背景组合逐对实算（WCAG 相对亮度），**16 项全部达标，0 项不合格**。

| 用途 | 对比度 | 结论 |
|------|--------|------|
| 正文（纸底 15px） | 12.84:1 | AA |
| 栏目标题（卡片 19px） | 14.16:1 | AA |
| 首图标题（墨底 22px） | 8.98–11.18:1 | AA |
| 匾额金字（黑漆 21px） | 8.59:1 | AA |
| 次按钮文字（石青 14px） | 7.03:1 | AA |
| 题签文字（签条 12.5px） | 6.32:1 | AA |
| 瓦当篆字（陶饼） | 5.61:1 | AA |
| 登录按钮文字（朱漆 16px） | 5.39:1 | AA |
| 输入框占位字（凹槽 13.5px） | 5.13:1 | AA |
| 说明 / 时间（纸底 11–12px） | 4.86:1 | AA |

设计过程中有四处是**算出来才发现不合格**的，肉眼完全看不出来：说明文字曾只有 3.51、输入框占位字曾只有 3.23、匾额副题曾只有 3.70、深棕底上的标题曾只有 4.13。都已修正。

## 九、工程护栏

设计要能长期不走样，靠的不是自觉，是护栏。两条已挂进 `preflight:local`：

**`check:design-tokens`** —— token 定义区之外不允许出现写死的木色/纸色。
这条不是预防性的：第一次运行就审计出 **43 处**写死的暖棕，首图、匾额、展馆封面、登录页这些大面积的颜色全都没走变量——这正是前两轮「改了木色却看不出变化」的原因。人眼查不出来，只能靠机器。

**`check:font-subset`** —— 管三件事：字体产物与源文件一致、所有写死的中文都在子集内、主包体积留有余量。三条都做过变异验证。

## 十一、还没定的两件事

1. **靛青备选**目前是把主推方案换个颜色，材质语言没跟着换（现在是「蓝色的木纹」）。真要走靛青，材质应换成青砖 / 靛染 / 青瓷开片。
2. **实拍素材**：首图与封面现在是纯色 + 祥云占位。校方若能提供书院活动、讲座现场、书法作品、图书室的实拍图，这几块换成照片会明显更厚——装裱那一套就是为此准备的。
