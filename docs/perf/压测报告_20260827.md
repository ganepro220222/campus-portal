### 浏览 P95 986ms（目标 500ms）

| 因素 | 说明 |
|------|------|
| 环境 | staging 单 ECS 混部（API + MySQL + Redis），非生产级 RDS 分离 |
| 并发模型 | 200 并发 × 5 接口轮换，短窗口内打满单 JVM |
| 对比 | 同机 dev 归档 P95≈503ms；从 Windows 公网打 staging IP 时 P95≈10702ms（**无效**，须本机 loopback） |
| 功能 | 400/400 成功，无 4xx/5xx，接口路径正确 |
| 后续 | 生产切 RDS + Redis 独立实例后可复测；或 staging 升配 / 加缓存后再跑一轮 |

### 报名 P95 1978ms

staging 单节点 50 并发写（登录 + 报名事务），P95 高于浏览类只读接口，属预期；**门禁项为不超卖**，已 PASS。

### staging 压测操作备忘

**勿用** `source .env`（`DB_URL` 中 `&` 会被 shell 拆成后台任务）。**勿用** `$MYSQL_ROOT_PASSWORD`（compose 未导出该变量）。

```bash
cd /opt/shuyuan
DB_USERNAME=$(grep '^DB_USERNAME=' .env | cut -d= -f2- | tr -d '\r')
DB_PASSWORD=$(grep '^DB_PASSWORD=' .env | cut -d= -f2- | tr -d '\r')

docker compose -f docker-compose.staging.yml exec -T mysql \
  mysql -u"$DB_USERNAME" -p"$DB_PASSWORD" shuyuan \
  -e "SELECT id, title, quota, enrolled_count FROM activity WHERE id=99;"

docker compose -f docker-compose.staging.yml exec -T mysql \
  mysql -u"$DB_USERNAME" -p"$DB_PASSWORD" shuyuan \
  < sql/patch-loadtest.sql

BASE_URL=http://127.0.0.1:8080 CONCURRENCY=50 \
  node scripts/load/enroll-concurrent.mjs
```

**报名压测前临时放宽登录限流**（50 并发登录共用源 IP，默认 10/min 不够）：

> **注意：** `docker compose restart` **不会**读取 `.env` 新增变量，须 `up -d --force-recreate backend`。  
> 压测脚本从 ECS 宿主打 `127.0.0.1:8080` 时，backend 容器看到的客户端 IP 通常是 **Docker 网桥**（如 `172.18.0.1`），清 Redis 时须删 `ratelimit:login:*` 全部键，不要只删 `127.0.0.1`。

```bash
# .env 追加（二选一：放宽登录 或 压测期间全关限流）
echo 'SHUYUAN_RATE_LIMIT_LOGIN_PER_MINUTE=100' >> .env
# 或：echo 'SHUYUAN_RATE_LIMIT_ENABLED=false' >> .env

# 必须 recreate 才注入新 env（restart 无效）
docker compose -f docker-compose.staging.yml up -d --force-recreate backend
sleep 20
curl -sf http://127.0.0.1:8080/api/v1/health | head -1

# 确认变量已进入容器（应输出 100 或 false）
docker compose -f docker-compose.staging.yml exec -T backend \
  printenv SHUYUAN_RATE_LIMIT_LOGIN_PER_MINUTE SHUYUAN_RATE_LIMIT_ENABLED

REDIS_PASSWORD=$(grep '^REDIS_PASSWORD=' .env | cut -d= -f2- | tr -d '\r')
# 清空所有登录限流计数
docker compose -f docker-compose.staging.yml exec -T redis \
  redis-cli -a "$REDIS_PASSWORD" --no-auth-warning --scan --pattern 'ratelimit:login:*' \
  | while read -r k; do
      [ -n "$k" ] && docker compose -f docker-compose.staging.yml exec -T redis \
        redis-cli -a "$REDIS_PASSWORD" --no-auth-warning DEL "$k"
    done
```
