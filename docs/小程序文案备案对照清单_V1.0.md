# 云端书院小程序 · 文案备案对照清单 V1.0

> **编制目的**：对照 `docs/` 内产品文档与小程序实际代码，记录 2026-07 备案口径下的**纯文案调整**（不涉及 UI 视觉资产变更）。
>
> **原则**：以**当前小程序代码**为准；开发文档（如《技术实施方案 V1.2》）中仍沿用「新闻资讯」等旧称处，前端已按备案要求调整，后台/CMS 需另行同步。
>
> **变更范围**：仅修改用户可见字符串、Mock 兜底数据、默认配置文案；**不修改**校徽、书法字、海报顶栏机构名等 VI 资产。

## 6. 未修改项（内容性「文化」字样）

以下内容**属于课程/活动/展馆真实名称或正文**，非功能模块命名，本次** intentionally 保留**：

- Mock 课程名：如「阳明心学十二讲」「屯堡文化探源」
- Mock 动态标题：如「中华文化书院举办…专题讲座」
- 展馆名：如「文化千岛艺术馆」
- 课程分类：「阳明文化」（专题维度，非 Tab 名）
- 搜索热词 / AI 示例问题：如「什么是阳明文化？」（用户提问示例）
- 展馆分类：「文化艺术」等（来自校方展馆体系）

若备案审核对**正文内容**另有要求，需单独梳理 CMS 已发布文章，不在本清单代码变更范围内。
