# 云端书院 · 上线手把手：账号归属 · 域名与 DNS · 逐步购买

> 配套：《云资源采购指引与三年成本清单》《部署手册 V1.0》《甲方配合事项清单》。
> 本文专讲最容易卡壳、且**必须校方配合**的三件事：**账号该用谁的、域名怎么定、DNS 怎么配**，并给出可直接发给学校信息中心的申请话术。

## 一、账号归属：谁的手机号 / 谁的主体（先定，别买错）

有三类账号，**"实名主体"比"登录手机号"重要得多**——主体决定发票、归属、合规、你离场后学校能否继续掌控。

| 账号 | 实名主体（关键） | 登录手机号/联系人 | 谁来操作 | 说明 |
|---|---|---|---|---|
| **微信小程序** | **学校**（事业单位/组织） | 管理员老师的手机号 + 微信（需人脸核身） | 校方注册，你协办 | AppID/Secret 属学校账号；用老师手机号做管理员是**正常且必需**的 |
| **云账号（阿里云）** | **建议=学校**（用学校法人/统一社会信用代码实名） | 可用管理员老师手机号做账号联系人 | 你拿 **RAM 子账号** 干活 | 主体=学校 → 发票开给学校、归属清晰、你离场学校仍掌控 |
| **域名** | 随云账号（学校） | 同上 | 你协办 | 若用学校 `edu.cn` 子域，则本就归学校，见第二节 |

**推荐做法（归属最干净）：**
1. 让学校用**学校主体**做阿里云企业实名（要学校的**事业单位法人证书/统一社会信用代码**、对公信息）。登录手机号可以填**小程序管理员老师**的号（当账号联系人）。
2. 学校在云账号里给你开一个 **RAM 子账号**（子用户），授权 ECS/RDS/OSS/CDN 等权限，你用子账号部署运维。
3. 这样：**账单/发票=学校**，**日常操作=你**，**最高权限=学校**。将来你退场，学校收回子账号即可，无需"过户"。

> 备选（不推荐长期）：你先用**自己主体**注册云账号建好，之后走阿里云"**账号过户/实名变更**"转给学校——手续比一开始就用学校主体麻烦，且过户期间发票归属乱。**能一步到位就用学校主体。**

**微信小程序**这块（校方必做，已在《甲方配合事项清单》P0 第 1–2 项）：
- 主体=学校，类目配合审核；
- 管理员=某老师（手机号+微信+人脸）；
- 认证 300 元/年；
- 拿到 **AppID / Secret** 后**线下加密交给你**（填后端 `WX_APPID/WX_SECRET`）。

## 二、域名与 DNS：`shuyuan.gzcpu.edu.cn` A 记录方案（你问的核心）

### 2.1 你的判断对不对？

**对，而且是推荐方案之一。** 你观察到 `www.gzcpu.edu.cn` 大概率在校内服务器（威胁情报平台查不到阿里云等公有云特征）——这**不影响**用它的子域名指向我们的云服务器。DNS 的每条记录可以各指各的地方：
- `www.gzcpu.edu.cn` → 继续指校内服务器（A 记录 → 校内 IP）；
- `shuyuan.gzcpu.edu.cn` → **由学校在权威 DNS 加一条 A 记录，指向我们云 ECS 的公网 IP**。

两者互不影响。**所以是的：让校方信息中心加一条 `shuyuan` 子域的 A 记录，指向我们的云服务器公网 IP。**

### 2.2 ⚠️ 关键的坑：edu.cn 域名的"备案"

用学校子域省了买域名、也更"官方"，但有一个**必须提前确认**的政策问题：

- 大陆公有云（阿里云/腾讯云）**对外提供网站服务，域名需完成 ICP 备案/接入备案**；否则云厂商会**拦截 80/443 公网访问**。
- `edu.cn` 域名由**中国教育和科研计算机网（CERNET）**管理，**不是商业注册商域名**。它在阿里云自助备案系统里**往往无法直接提交/接入备案**，可能需要走 CERNET/学校信息中心的特殊渠道，或提供学校证明。
- **我无法拍胸脯保证 `shuyuan.gzcpu.edu.cn` 一定能在阿里云顺利"接入备案"**——这取决于当期政策与学校信息中心。**必须双向确认**：
  1. 问**阿里云备案客服**："edu.cn 子域名能否在阿里云做接入备案？需要什么材料？"
  2. 问**学校信息中心**："gzcpu.edu.cn 是否已在工信部/教育网备案？能否为子域 shuyuan 出具接入证明/走教育网备案？"

### 2.3 两条路，先确认再动手

| | 方案 A：用学校子域 `shuyuan.gzcpu.edu.cn` | 方案 B：自购商业域名（保底） |
|---|---|---|
| 官方感 | 强（就是学校域名） | 一般 |
| 域名费 | 0（学校已有） | ~70/年 |
| 备案 | **需确认 edu.cn 能否在阿里云接入备案**（可能要 CERNET/信息中心配合） | 标准流程，阿里云自助备案，主体=学校，约 1–3 周 |
| DNS | 校方加 A 记录（+ 证书验证 TXT） | 你在阿里云控制台自助配置 |
| 建议 | **首选**，但**先把备案确认清楚**再买机器 | **备用**：若 A 的备案走不通，立刻切 B，不耽误上线 |

> **策略**：**并行**——让学校信息中心去确认 edu.cn 子域备案的同时，你可以**先注册一个便宜的商业域名占位并提交备案**（主体=学校）。哪条先备案通过就用哪条；商业域名没用上损失也就几十块。

### 2.4 需要校方配的 DNS 记录（方案 A）

上线时你会给学校信息中心这样一张表（IP/值到时用真实的替换）：

| 主机记录（子域） | 类型 | 记录值 | 用途 |
|---|---|---|---|
| `shuyuan` | **A** | 我们云 ECS 的**公网 IP** | 小程序 API + 管理后台 + exhibits |
| `_acme-challenge.shuyuan`（临时） | **TXT** | 证书机构给的验证串 | 申请**免费 HTTPS 证书**用（签完可留可删） |
| `cdn-shuyuan`（可选，走 CDN 时） | **CNAME** | 阿里云 CDN 给的 `xxx.kunlun.com` 加速域名 | 视频/图片/课件分发 |

> 若嫌 edu.cn 备案 + 媒体子域证书太折腾，**媒体可先直接用阿里云 CDN 自带的已备案加速域名**（不是学校域名，但省事），主站再用学校子域。二者可分开。

### 2.5 HTTPS 证书（免费）

- 为 `shuyuan.gzcpu.edu.cn` 申请**免费 DV 证书**（阿里云免费证书 / Let's Encrypt 均可）。
- 验证方式二选一：**DNS 验证**（校方加一条上面的 `_acme-challenge` TXT，最稳）或 **文件验证**（需域名已能访问）。
- 装到 Nginx 443（配置见《部署手册》5.5）。证书 90 天~1 年，到期前续。

## 三、逐步购买（阿里云为例，click 级）

> 前提：已按第一节定好**学校主体的云账号 + 你的 RAM 子账号**。地域**全程选同一个、就近**（如"华南/西南"就近地域）。

1. **实名 & 地域**：登录云账号 → 完成学校企业实名 → 记住选定地域。
2. **域名 + 备案（最先做，因为要等）**
   - 方案 A：把 edu.cn 子域备案问题抛给信息中心（见 2.2 话术）；
   - 方案 B：控制台"域名" → 买一个 `.cn`/`.com.cn` → "备案"入口 → **主体填学校** → 按向导传资质 → 提交，等 1–3 周。
3. **买 ECS**：控制台"云服务器 ECS" → 创建实例 → 规格 **4 vCPU / 8 GiB** → 系统盘 **ESSD 40–80G** → 公网带宽 5Mbps（或按量）→ **购买时长选 3 年**（锁价）→ 镜像选 **Ubuntu 22.04 / Alibaba Cloud Linux** → 创建。记下**公网 IP**（这就是给学校 A 记录的值）。
4. **（方案②稳妥版再买）RDS + Redis**：
   - "云数据库 RDS" → MySQL 8.0 → 2C4G → 100G → **同地域、同 VPC** → 3 年；
   - "云数据库 Redis" → 1 GiB → 同地域同 VPC → 3 年。
5. **OSS**："对象存储 OSS" → 创建 Bucket → **同地域**、**私有读写** → 记住 Bucket 名/Endpoint（填后端 `OSS_*`）。
6. **CDN**："CDN" → 添加加速域名（媒体子域）→ 源站选 OSS Bucket → 拿到 **CNAME 值**（给学校配 `cdn-shuyuan` CNAME）→ 先买 **1TB 流量包**。
7. **免费证书**："数字证书/SSL" → 申请免费 DV → 绑 `shuyuan.gzcpu.edu.cn` → DNS 验证（给校方 TXT）。
8. **安全组**：ECS 安全组**只放行 443 和 80**（80 仅做跳转）；**务必不要**对公网开放 3306/6379。
9. **百炼 AI**："百炼/模型服务" → 开通 → 建 AccessKey → 设**额度预警** → 填后端 AI key。
10. **部署**：把 A 记录/证书配好后，按《部署手册》上 staging → 压测 → 切正式。

## 四、微信小程序侧（校方账号里配，你给值）

1. 小程序**认证**（300/年）、类目审核 —— 校方。
2. **服务器域名**（公众平台"开发-开发管理-服务器域名"）：
   - request 合法域名：`https://shuyuan.gzcpu.edu.cn`
   - uploadFile / downloadFile 合法域名：同上（或 OSS/CDN 域名）
   - **这些域名必须已备案 + HTTPS**，否则加不进去、小程序请求会被拦。
3. **业务域名**（web-view）：加 VR 外链域名（`720yun.com` 等，见《甲方配合事项清单》第 6 项）。
4. AppID/Secret 线下交给你填后端。

>
> 感谢配合，以上任一方式确定后我方即可推进上线。

## 六、一页速记

- **账号**：云账号**实名=学校**、你用 **RAM 子账号**；小程序**主体=学校**、管理员=老师手机号；发票都给学校。
- **域名**：首选 `shuyuan.gzcpu.edu.cn` + **学校加 A 记录指向云 ECS 公网 IP**；**但先确认 edu.cn 能否在阿里云接入备案**，走不通就用**学校主体的商业域名**保底（并行推进最稳）。
- **证书**：免费 DV，DNS 验证（校方加 TXT）。
- **小程序合法域名**：必须**已备案 + HTTPS** 才能加。
- **安全组**：只开 443/80，禁开 3306/6379。
- **顺序**：定账号主体 → 域名与备案（最先，要等）→ 买 ECS/存储/CDN → 证书 → 配 DNS → 部署压测 → 上线。
