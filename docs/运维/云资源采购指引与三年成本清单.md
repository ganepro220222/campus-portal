# 云端书院 · 云资源采购指引与三年成本清单

> **用途**：手把手指导「买哪些云资源、怎么买最省、三年各花多少」。
> **依据**：本项目真实代码依赖（Spring Boot + Vue 后台 + 微信小程序 + exhibits 静态 3D + MySQL + Redis + OSS + CDN + 百炼 AI）、
> 《资源配置清单_1.3万学生》《乙方成本估算_3年》《技术实施方案 V1.2》，以及 2026 年初阿里云公开价。
> **规模**：贵州交通职业大学，在校生约 13,000；按验收口径 **200 API 并发 / 50 报名并发 / 数百同时在线** 设计。
> **金额**：人民币，**均为估算区间**，实际以采购页与云账单为准。

---

## 〇、先弄清三件事（买之前）

1. **地域就近**：选 **华南/西南就近地域**（如可用「乌兰察布/贵阳」等，OSS/ECS/RDS **放同一地域**，否则跨地域流量要另收费）。本项目 `OSS_ENDPOINT` 已按 `cn-guizhou` 类地域设计。
2. **ICP 备案（必须、免费、要提前）**：域名对公网提供服务，**必须先 ICP 备案**（约 7–20 天）。微信小程序的 request/upload/download 合法域名**必须是已备案 + HTTPS 的域名**。**建议备案主体 = 学校**（甲方资质）。**先买域名 → 提交备案 → 备案下来再上线**，别等到最后卡壳。
3. **新用户活动价只有一次**：ECS/RDS 的「新用户首购价」很低但**只享一次、且续费会上浮 20–30%**。**对策：一次性买 3 年（预付 3 年）把低价锁死**——这是本清单比按年续费更省的关键。

## 二、两套方案（都已按 3 年预付锁价优化）

### 方案①「省钱版」——单台 ECS 自管 MySQL/Redis（最省）
- **1× ECS 4C8G**（3 年预付），用 Docker 在同机跑 **MySQL + Redis + Spring Boot + Nginx**；
- OSS + CDN 承载媒体；staging 用你本机 `docker-compose.dev.yml`，**不额外买预发机**。
- **代价**：数据库备份/高可用要你自己管（用定时 `mysqldump` → 传 OSS，脚本化即可）。
- **适合**：预算最紧、数据非强监管、你愿意做基本运维。数百在线的文化类应用，这套完全够用。

### 方案②「稳妥版」——托管 RDS + 云 Redis（省心，推荐给学校长期）
- **1× ECS 4C8G** + **RDS MySQL 2C4G 基础版** + **云 Redis 1G**（都 3 年预付）；OSS + CDN。
- **优点**：RDS 自动备份、宕机自愈概率低、少运维；数据更稳。
- **适合**：希望少操心、数据要可靠、后续要交给学校长期维护。

> 两套的**媒体（OSS+CDN）、域名、微信、AI** 完全相同，差别只在「DB/Redis 自管 vs 托管」。

## 四、购买顺序（照着做）

1. **注册云账号 + 企业实名**（建议用学校主体，或你先代注册后过户）。
2. **买域名**（`.com.cn`/`.edu.cn` 视资质），**立即提交 ICP 备案**（等 1–3 周，别耽误）。
3. **买 ECS 4C8G，选 3 年预付**，地域=就近；系统盘 ESSD 40–80G。
4. （方案②再买）**RDS MySQL 2C4G 基础版** + **云 Redis 1G**，同地域、同 VPC。
5. **开 OSS Bucket**（私有读）+ **开 CDN**、绑加速域名；先买 **1TB CDN 流量包**。
6. **申请免费 SSL 证书**，装到 Nginx。
7. **微信公众平台**：小程序**认证（交 300）** → 配置服务器合法域名（必须已备案+HTTPS）。
8. **开通百炼**，建 AK/额度预警；填后端 AI api-key。
9. 安全组：**只开 443（+80 跳转）**，**绝不**对公网开 3306/6379。
10. 按《部署手册》部署 → staging 跑通 → 压测 → 切正式。

## 五、省钱技巧（在满足验收前提下）

- **3 年预付锁价**：ECS/RDS/Redis 一次买 3 年，规避第 2/3 年续费上浮（本清单已按此估）。
- **高校折扣**：查阿里云「[云工开物 / 高校计划](https://university.aliyun.com/)」，云资源三年可能再省 **数千元**（以审核为准）。
- **DB/Redis 自管**（省钱版）：省下 RDS+Redis 约 **700/年**，代价是自己做备份。
- **CDN 先小后大**：先买 1TB 包，按监控再扩；别一上来买大带宽。
- **OSS 资源包**：存储/下行流量买**预付资源包**比按量便宜。
- **staging 不单独买**：用你本机 `docker-compose.dev.yml` 当预发，省一台机。
- **AI 控费**：限次已实现（问答 20 次/人/日、后台文案辅助 100 次/人/日，见 `shuyuan.rate-limit.ai-per-day`
  与 `shuyuan.ai.daily-limit`），把 AI 压在中档 ~500–700/年。
  **「相同问题 24h 缓存」目前尚未实现**——`AiClientService.chat()` 每次都直连模型。
  这一条也不宜简单照搬：若按「问题原文完全一致」做缓存键，自然提问几乎不会命中——
  「如何报名」与「怎么报名」会被算成两个问题。真要做，键应取归一化后的问题或检索命中的片段集合
  （知识库检索本身用的是 2–4 字的字符 n-gram，对措辞差异不敏感，可以复用同一套归一化）。
  上面的估算按**无缓存**计，属保守值；日后接入只会更省，金额无需上调。
- **免费证书**：SSL 用免费 DV，别买付费证书。
