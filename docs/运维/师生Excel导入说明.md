# 师生 Excel 导入说明

## 是否需要固定格式？

**需要遵循列含义，但不必逐格手抄到空白模板。**

系统提供「下载导入模板」作为字段说明与示例，但校方若已有内部师生名册，通常只需在 Excel 里**改表头列名**（或保留常见别名），即可直接上传导入。

## 必填与可选字段

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 学号 | **必填** | 学生填学号、教师填工号，同一列。全校唯一；已存在则跳过。学号 12 位、工号 7 位，只能是数字（位数按校方样例定，可在部署时改，见《环境变量说明》） |
| 姓名 | **必填** | 显示名称 |
| 学院 | 可选 | 用于个人资料展示 |
| 年级 | 可选 | 如 2024 |
| 手机号 | 可选 | |
| 身份证号 | 可选 | 用于生成初始密码（后 6 位）；填了会核对 18 位和校验位；无则取学号 / 工号后 6 位 |

单次导入上限 **5000 行**；格式 `.xlsx` / `.xls`。

## 先把学号、身份证两列设为文本

Excel 的数字只保留 15 位有效数字。身份证列是数字格式时，18 位号码的末 3 位会变成 000，
算出的初始密码就是错的；长学号在窄列里还会显示成 `1.23457E+11` 这样的科学计数法，复制出来后几位就没了。

所以粘贴之前，先选中「学号」「身份证号」两列 → 设置单元格格式 → **文本**，再粘贴原始号码。
导入时会拦下这几种情况，失败明细里写明原因：

- 学号 / 工号位数不对、带字母或小数点、是科学计数法；
- 身份证号不是 18 位、末 3 位是 000、校验位不对。

号码里的空格、全角数字会自动去掉或转成半角，不算错。

## 支持的表头别名（改列名即可）

校方表头与下列任一名称一致即可被识别（**列顺序不限**，多余列可保留）：

| 系统字段 | 可识别的表头 |
|----------|----------------|
| 学号 | 学号、学生学号、学号/工号、工号、账号、student_no |
| 姓名 | 姓名、学生姓名、名字、真实姓名、name |
| 学院 | 学院、院系、所在学院、学院名称、college |
| 年级 | 年级、入学年级、grade |
| 手机号 | 手机号、手机、联系电话、电话、mobile、phone |
| 身份证 | 身份证号、身份证、证件号码、身份证号码、id_card |

### 推荐操作（无需手抄）

1. 打开校方导出的 Excel（教务/学工系统导出均可）。
2. 将第一行表头改为上表对应名称（如「院系」→「学院」）。
3. 删除与导入无关的列（可选，不影响导入）。
4. 在管理后台「师生账号」页上传。

若表头差异较大，可用 Excel 公式引用原表数据到新表（如 `=Sheet1!B2`），**批量引用比手工抄写快得多**。

## 导入后账号规则

- **初始密码**：身份证后 6 位；无身份证则学号 / 工号后 6 位。
- **身份证号不入库**：它只在导入的那一刻用来算出初始密码，随即丢弃，**不写入任何数据表**
  （`member_profile` 里根本没有这一列）。所以后台「师生账号」列表看不到身份证，
  也无法事后从系统里导出——需要向校方说明数据留存范围时，这一条可以直接引用。
- **忘记密码**：已绑定微信的学生可在登录页用微信验证后自助设置新密码。未绑定微信
  （不接短信）时，在后台「师生账号」页点该行的「重置密码」，会生成一个只显示一次的
  临时密码，转告本人即可。已绑定但仍要后台重置时，旧密码立即失效且不生成临时密码，
  通知对方用微信打开小程序设置；微信号也丢了，须先「解绑微信」再重置。对方登录后
  会被要求立即修改，且其他设备上的登录状态同时失效。
- **首次登录**：学生须在小程序修改初始密码后方可正常使用。
- **微信登录**：须绑定校方导入的学号账号（不自动注册新用户）。
- **换微信 / 微信号被盗 / 当初绑错了**：在后台「师生账号」页点该行的「解绑微信」，
  之后本人即可用新微信重新绑定这个学号。解绑**只解除微信绑定**：学号密码照常能登，
  账号不会被禁用，收藏、报名、学习进度、积分、徽章一概不动；但对方手机上当前的
  登录状态会立即失效。
  > 不要用「清退」来处理换微信——清退会清空学号，重新导入产生新的用户 ID，
  > 而报名、进度、积分都挂在旧 ID 上，等于把这名学生一个学期的记录清零。

## 导入失败怎么办？

导入结果会显示成功/跳过/失败数量。若有失败行：

1. 弹窗内可查看前 50 条错误摘要；
2. 点击「**导出上次失败明细**」下载 Excel，含行号、学号、姓名、失败原因；
3. 修正后重新导入（已成功的学号会自动跳过）。

## 常见失败原因

- 学号或姓名为空
- 学号 / 工号位数不对或不是纯数字（已存在的老账号照旧跳过，不查格式）
- 身份证号不对：位数、末 3 位是 000、校验位
- 学号已存在（显示为「跳过」，非失败）
- 文件非 Excel 或超过 5000 行

## 后续可增强（按需）

若某校表头与上述别名仍不匹配，可评估：

- 管理端「列映射」配置（上传后手动对应列）
- 与教务系统 API 对接（免 Excel）
- CAS / 统一身份认证单点登录（见《CAS 对接评估说明》）
