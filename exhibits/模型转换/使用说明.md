# OBJ → GLB 转换器 · 使用说明

将 **OBJ + MTL + 贴图（jpg/png）** 转为**自包含 GLB**（贴图内嵌，单文件可用于三维展品），支持批量。提供**图形界面**与**命令行**两种入口，共用同一套转换引擎。

---

## 一、图形界面

### 环境要求

图形界面依赖 **tkinter**。`exhibits` 目录下的便携 Python 为嵌入式版本，**不含 tkinter**，无法启动窗口，仅适用于命令行（见第四节）。

启用图形界面需满足以下任一条件：

- 已安装 **完整 Python 3.12+**（安装时勾选 **tcl/tk** 与 **Add Python to PATH**），或
- 已打包为 **单文件 exe**（见第二节）。

### 首次准备

1. 若无完整 Python：从 [python.org](https://www.python.org/downloads/) 下载安装，勾选 tcl/tk。
2. 双击 **「安装转换依赖.bat」**（或 `python -m pip install trimesh pillow numpy`）。脚本会为检测到的 Python 环境安装依赖（便携版与完整版若并存则分别安装）。

### 操作步骤

1. 双击 **「打开转换器.bat」**（启动时会自动选择带 tkinter 的解释器）。
2. **第一步**：「添加文件…」或「添加文件夹…」，将模型加入列表。
3. **第二步**：选择输出目录（留空则默认为输入目录下的 `output_glb`）。
4. **第三步**：贴图选项可保持默认，点击 **开始转换**。
5. 完成后点击 **打开输出目录**，查看 GLB、`manifest.csv` 与 `*.transform.json`。

> 每个 `.obj` 须与同目录下的 `.mtl`、贴图位于同一文件夹；程序会自动关联。

## 二、打包为 exe（可选）

适用于无需安装 Python 的分发场景。须在 **Windows** 上打包（Linux / Mac 无法直接生成 Windows exe）。

1. 确认本目录文件齐全（含 `obj2glb_gui.py`、`batch_glb.py`、`glb_utils.py` 等）。
2. **推荐**：双击 **`build-exe-venv.bat`**（独立 venv，避免 Anaconda 中 PyQt / PySide 冲突）。
3. 若本机为官方 Python 且环境干净，也可双击 **`build-exe.bat`**。
4. 产物路径：`dist\OBJ2GLB-Converter.exe`，可重命名为 `OBJ转GLB转换器.exe` 后分发。

**常见问题：**

| 现象 | 处理 |
|---|---|
| Anaconda 同时存在 PyQt5 与 PySide6 | 使用 `build-exe-venv.bat` |
| bat 在含括号的路径下异常 | 目录名避免使用 `()` |

## 三、贴图与几何选项

| 选项 | 作用 | 默认 |
|---|---|---|
| 贴图最大边长 | 超过则等比缩小（2048 适用于网页展示） | 2048 |
| 贴图格式 | 自动：有透明通道用 PNG，否则 JPEG | 自动 |
| JPEG 质量 | 数值越大越清晰、体积越大 | 85 |
| 不重编码贴图 | 仅缩放、不改编码（体积较大） | 关 |
| 导出 transform.json | 输出归一化参数，可填进展品 config | 开 |
| 覆盖已存在 GLB | 同名文件是否覆盖 | 关 |

**体积说明：**

- 网格几何不做有损压缩。
- 体积主要来自贴图：默认 2048 边长 + JPEG 重编码；勾选「不重编码」则更接近无损、体积更大。

**输出文件：**

| 文件 | 说明 |
|---|---|
| `*.glb` | 文件名含内容指纹（如 `模型-a1b2c3d4.glb`），内容变更则文件名变更 |
| `manifest.csv` | 批量清单：体积、网格数、状态等 |
| `*.transform.json` | 归一化参数：scale / offset / floorOffsetY |

**格式限制：** 不支持 FBX；请先在 Blender 等工具中导出为 GLB 或 OBJ。

## 四、命令行版

双击 **「转换模型.bat」**，将含 obj / mtl / 贴图的文件夹拖入窗口并按提示操作。适用于批量转换、脚本集成。

等价命令：

```bash
python obj2glb.py 模型.obj --max-texture 2048
python batch_glb.py 输入目录 -o 输出目录 --max-texture 2048
```

便携 Python 路径：`exhibits\_runtime\python\python.exe`（与编辑器工作台共用，仅适用于命令行）。
