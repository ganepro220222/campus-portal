# 登录与账号

怎么登录云端书院小程序？登录时填什么？学号还是工号？忘记密码怎么办？微信能解绑吗？怎么解绑微信？

账号来源：云端书院的账号不能自己注册。所有师生账号由学校或学院的管理员在管理后台统一导入或新增。登录时填学号 / 工号：学生填学号，教师填工号，两者用的是同一个输入框，不用区分身份。如果你用微信打开小程序后提示需要绑定，而你填的学号 / 工号又登录不上，说明系统里还没有导入你，请联系学院管理员。

有两种登录方式：

第一种是微信一键登录。在登录页点「微信一键登录」，这个微信已经绑定过就直接进入；还没绑定过时，页面会变成「绑定学号 / 工号」，填一次学号 / 工号和密码即可完成绑定，以后点微信就能直接进，不用再输密码。一个学号 / 工号只能绑定一个微信，一个微信也只能绑定一个学号 / 工号。

微信能不能解绑：学生不能在小程序里自己解绑。换微信、微信号丢失或当初绑错了，请联系学院管理员。管理员在管理后台的「师生账号」页面找到你这一行，点「解绑微信」即可。解绑后你就能用新微信重新绑定这个学号 / 工号，收藏、报名、学习进度、积分和徽章都不会丢失。解绑不影响学号 / 工号密码登录；但原来那个微信里的登录状态会立即失效，需要重新登录。如果提示「该学号 / 工号已绑定其他微信」，也是走同一条解绑流程。

第二种是用学号 / 工号和密码登录。在登录页点「用学号 / 工号登录」，输入学号 / 工号与密码即可。登录成功后如果还没绑定微信，会询问是否现在绑定：不绑也能继续用，只是下次还要输密码；绑定后点微信就能直接进，忘记密码也能自己找回。

首次登录必须修改密码。第一次登录用学院告知的初始密码，进门后系统会要求你换成新密码，改完才能正常使用；改完之后如果还没绑定微信，也会问一次是否绑定。已经登录、还记得旧密码时，可在「我的」页面点「修改密码」。新密码要求：至少 8 位，必须同时包含字母和数字，并且不能与当前密码相同。

忘记密码怎么办：如果这个微信已经绑定过学号 / 工号，在登录页点「忘记密码」，用微信验证后即可直接设置新密码，不必再找管理员。如果微信还没有绑定，小程序无法自助找回（不接短信），请联系学院管理员在管理后台「师生账号」页点「重置密码」，用当面或电话告知的临时密码登录后再修改。微信号和密码都丢了，请管理员先解绑微信再重置，才能得到可告知的临时密码。管理员重置已绑定微信的账号时，不会再给临时密码，请用微信打开小程序设置新密码。

密码输错太多次：连续输错会暂时锁定这个学号 / 工号，提示里会写明要等几分钟，到时间自动解锁。想不起密码就别反复试，按上面的方法找回。

登录遇到问题：登录页底部有「无法登录？」，里面按常见情况写了该怎么办，最后有学院的联系方式，不登录也能看到。

登录状态会保持一段时间，过期后需要重新登录。如果你修改了密码，其他设备上的登录状态会立即失效，需要用新密码重新登录。

账号被停用：如果提示账号已停用或无法登录，可能是管理员停用了该账号，或者该账号已被清退。请联系学院管理员确认。

哪些功能必须登录：收藏、点赞、报名活动、下载资源、记录课程学习进度、获得积分与徽章、使用知识问答、查看消息中心、提交意见反馈。浏览动态、展馆、课程列表和详情不需要登录。

退出登录：在个人中心可以退出当前账号。退出后报名、学习进度等个人数据不会丢失，重新登录即可看到。

换手机：换手机后用已绑定的微信，或学号 / 工号和密码重新登录即可，个人数据还在。微信丢了、换微信号或当初绑错了，不能自己解绑，要联系学院管理员解绑微信。
