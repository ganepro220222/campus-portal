# 课程与学习资源

怎么看课程？学习进度怎么算？课程什么时候算完成？资源在哪里下载？

课程列表：点击底部「课程」标签进入。只有管理员已上架的课程才会显示。点击课程进入详情页，可以看到课程标题、讲师、简介与封面，点击播放进入播放页。

学习进度：播放页会自动记录你看到的位置和累计进度，进度以百分比显示。下次再进入这门课程，会从上次看到的位置附近继续。进度记录需要先登录，未登录时不会保存。

课程什么时候算完成：观看进度达到 90% 及以上时，这门课程会被标记为「已完成」。完成一门课程可以获得积分。已经完成的课程不会因为你重新观看而退回未完成状态。

进度不动或进度异常：系统对进度上报有校验，异常的进度（例如刚打开就跳到接近结尾）不会被计入。正常观看即可，不需要额外操作。如果确实观看了却没有记录，先确认是否处于登录状态。

课程字幕：部分课程配有字幕，播放时可以打开。字幕由管理员上传或配置后随课程下发，不是所有课程都有。

学习资源：资源列表提供可下载的学习资料，包括 PDF、Word、PPT 和音视频文件。可以从课程板块或首页的资源入口进入。点击下载即可，下载需要先登录。下载资源可以获得积分，每天有次数上限。

资源下载失败：如果下载没有反应或提示失败，先确认网络是否正常，再确认是否已登录。部分大文件下载需要一点时间，请耐心等待。已下架的资源不能下载。

我的下载记录：个人中心的「下载」数字是你的累计下载次数，可以查看下载过哪些资料。

学习徽章：个人中心有「学习徽章」页面。完成 3 门课程可以获得「学习先锋」徽章，其他徽章的条件见积分与徽章相关说明。

常见问法：怎么看课程？课程进度怎么算？看到多少算完成？为什么进度没有保存？课程有字幕吗？资源怎么下载？下载失败怎么办？下载记录在哪里？
