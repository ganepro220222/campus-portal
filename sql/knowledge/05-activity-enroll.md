# 活动报名

怎么报名活动？报名后要做什么？名额满了怎么办？可以取消报名吗？

怎么报名：在活动列表点击想参加的活动进入详情页，确认时间、地点与名额后点击报名，填写并提交报名表单即可。报名需要先登录。

报名时间：活动发布后即可报名，除非管理员另外设置了报名开始时间。报名截止默认是活动开始时间；活动一开始就不能再报名。如果活动写明了报名起止时间，则只在该时间段内可提交，开始时刻和截止时刻本身也允许报名（不会晚于活动开始）。还没到报名开始或已经截止时，报名按钮不可用。

要不要审核：活动分两种。不需要审核的活动，提交后状态直接是「已通过」；需要审核的活动，提交后状态是「待审核」，由管理员在后台审核。无论哪一种，提交的那一刻就已经占用名额，不用担心审核期间被别人挤掉。

名额：活动详情页会显示已报名人数和总名额，名额填 0 表示不限人数。名额报满后再提交会被拒绝，提示名额已满。如果有人取消报名或被拒绝，名额会释放，可以再来试试。

报名凭证：报名成功后会生成一个凭证码，同时提供签到二维码。可以在活动详情页点击「查看凭证」随时调出，二维码长按可以保存到相册。现场签到时出示凭证码或二维码即可。

取消报名：在活动详情页或个人中心的「我的报名」里可以取消。取消后名额会释放给其他人。取消后的报名不会再出现在「我的报名」列表里。

活动被取消：如果管理员取消了整个活动，你的待审核或已通过的报名会同步取消并释放名额，同时你会收到一条站内消息，可以在消息中心查看。

我的报名：个人中心的「报名」数字是你的有效报名数。「我的报名」列表只展示待审核、已通过、已拒绝三种状态，已取消的报名不再展示，请以消息中心的通知为准。如果某个活动已被取消而你的报名是「已拒绝」，这条记录仍会保留在列表里，副标题会显示「活动已取消」，并且不能再点进活动详情。

报名被拒绝：管理员拒绝时会填写原因。如有疑问请联系活动组织方或学院管理员。

积分：成功报名活动可以获得积分，每天一次。累计参加 5 次活动可以获得「活动达人」徽章。

报名提醒：报名提交、报名成功或审核结果会进入站内消息。完成微信订阅授权后，部分报名结果也会通过微信服务通知发送。目前请以活动详情中的开始时间为准，平台暂不提供活动临近提醒。
