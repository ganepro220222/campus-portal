# 个人中心与消息

个人中心有什么？消息中心在哪里？怎么看未读消息？首页铃铛为什么有红点？怎么提交意见反馈？反馈历史在哪里？关联小程序是什么？

消息中心在底部「我的」页面的「消息中心」，有未读消息时该菜单右侧显示数字徽标。首页右上角铃铛用于查看平台动态和公告，不是私人消息入口；有公告时铃铛会显示红点，点击后进入底部「动态」页。意见反馈也在「我的」页面：先看自己的反馈历史和处理状态，进入详情可查看原文、附图和管理员回复，列表底部再提交新反馈。

个人中心入口：首页左上角的头像图标，或底部「我的」进入。未登录时会提示先登录。

个人中心顶部显示你的昵称、所在学院和当前积分。下方是收藏、报名、下载三个统计数字，以及足迹入口。点击收藏、报名、下载的数字，或点击足迹，可以进入对应的列表页。

收藏：你收藏过的动态、课程、展馆、文创，可以在列表里取消收藏。
报名：你的有效报名记录，包含待审核、已通过、已拒绝三种状态。
下载：你下载过的学习资源记录。
足迹：你最近浏览过的内容，方便找回看过但没有收藏的内容。

个人中心的功能入口包括：

个人资料：查看和修改昵称、真实姓名、手机号、学院和年级。当前不能在资料页更换头像。绑定微信在登录时完成；首次登录或管理员重置密码后，系统会要求修改密码。
消息中心：查看系统发给你的站内消息。入口在「我的」页面的「消息中心」。
知识问答：进入知识问答的完整问答页面。
问答历史：查看你以前与知识问答的会话记录，点击任意一条可以继续那次对话。
关联小程序：书院合作的兄弟小程序或网页入口列表。
学习徽章：查看已解锁和未解锁的徽章及其条件。
意见反馈：查看自己的反馈历史和处理状态，也可以继续提交新反馈。
关于云端书院：小程序介绍与版本信息，隐私政策也可以从这里进入。

消息中心：报名成功、审核通过或拒绝、活动取消、活动临近提醒、意见反馈回复等会进入站内消息。入口在底部「我的」页面中的「消息中心」，有未读消息时该菜单右侧显示数字徽标。如果你在微信里授权了订阅消息，部分通知也会以微信服务通知的形式推送；没有授权时以站内消息为准，不会漏掉。

意见反馈：在「我的」页面点击「意见反馈」可查看自己的反馈历史和处理状态；进入详情可查看原文、附图和管理员回复；列表底部可继续提交新反馈。需要先登录。管理员回复后，消息中心也会收到对应通知。

关联小程序：这是「协同育人」板块，展示书院合作的其他小程序或网页。有的条目点击后会直接跳转到对方小程序，有的会展示图文简介或打开网页，具体取决于对方提供的对接方式。首页横向列表只展示可直接跳转的条目，完整列表在个人中心。

隐私政策：可以从「关于云端书院」页面进入，说明小程序收集哪些信息以及如何使用。

常见问法：个人中心在哪里？怎么改昵称？怎么改头像？消息中心在哪里？怎么看未读消息？首页铃铛为什么有红点？怎么看通知？怎么提交意见反馈？反馈历史在哪里？在哪里查看反馈处理进度？反馈会有人回复吗？关联小程序是什么？隐私政策在哪里看？
