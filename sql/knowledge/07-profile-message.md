# 个人中心与消息

个人中心有什么？消息中心在哪里？怎么提交意见反馈？关联小程序是什么？

个人中心入口：首页左上角的头像图标，或底部导航相关入口进入。未登录时会提示先登录。

个人中心顶部显示你的昵称、所在学院和当前积分，下方是四个统计数字：收藏、报名、下载、足迹。点击每个数字可以进入对应的列表页。

收藏：你收藏过的动态、课程、展馆、文创，可以在列表里取消收藏。
报名：你的有效报名记录，包含待审核、已通过、已拒绝三种状态。
下载：你下载过的学习资源记录。
足迹：你最近浏览过的内容，方便找回看过但没有收藏的内容。

个人中心的功能入口包括：

个人资料：查看和修改昵称、头像等资料，也可以在这里绑定当前微信或修改密码。
消息中心：查看系统发给你的站内消息。
智能问答：进入书院助手的完整问答页面。
问答历史：查看你以前与书院助手的会话记录，点击任意一条可以继续那次对话。
关联小程序：书院合作的兄弟小程序或网页入口列表。
学习徽章：查看已解锁和未解锁的徽章及其条件。
意见反馈：向书院提交使用问题或改进建议。
关于云端书院：小程序介绍与版本信息，隐私政策也可以从这里进入。

消息中心：报名成功、审核通过或拒绝、活动取消、活动临近提醒、意见反馈的管理员回复等都会以站内消息的形式发送到这里。首页右上角的铃铛图标有未读消息时会显示红点。如果你在微信里授权了订阅消息，部分通知也会以微信服务通知的形式推送；没有授权时以站内消息为准，不会漏掉。

意见反馈：填写反馈类型与内容后提交即可，需要先登录。提交后由管理员在后台查看处理；如有管理员回复，会发送到消息中心。反馈页当前用于提交新反馈，不展示反馈历史。

关联小程序：这是「协同育人」板块，展示书院合作的其他小程序或网页。有的条目点击后会直接跳转到对方小程序，有的会展示图文简介或打开网页，具体取决于对方提供的对接方式。首页横向列表只展示可直接跳转的条目，完整列表在个人中心。

隐私政策：可以从「关于云端书院」页面进入，说明小程序收集哪些信息以及如何使用。

常见问法：个人中心在哪里？怎么改昵称？怎么改头像？消息中心在哪里？怎么看通知？怎么提交意见反馈？反馈会有人回复吗？关联小程序是什么？隐私政策在哪里看？
