# 知识问答使用说明

知识问答是什么？能问什么？每天能问多少次？为什么有些问题答不上来？

知识问答是云端书院小程序内置的资料检索功能。它会先在书院知识库中检索与你的问题相关的资料，再把相关片段整理给你。首页有悬浮入口，个人中心有「知识问答」完整页面和「问答历史」。

能问什么：小程序怎么用、某个功能在哪里、怎么报名活动、积分怎么获得、忘记密码怎么办这一类使用问题，以及管理员录入知识库的书院文化相关内容。

不能问什么：知识问答只依据书院知识库作答，不是通用聊天机器人。与书院和本小程序无关的问题，例如常识百科、天气、算题、写代码等，它不会回答，会提示你换个问法。这不是故障，是设定如此。

为什么回答说「没有找到相关资料」：说明知识库里目前没有与这个问题匹配的内容。可以试着换一个更贴近书院或小程序功能的问法，或者用更短的关键词；也可以在首页搜索框里直接搜索动态、课程、展馆与资源。如果你认为这个问题应该能被回答，可以通过意见反馈告诉我们，管理员可以把相关资料补充进知识库。

每天能问多少次：每位用户每天有 20 次提问额度，按自然日计算，次日零点自动恢复。问答页顶部会显示「今日剩余 X 次问答」，用完时会提示「今日问答次数已用完，请明天再来」。

哪些情况不会扣次数：如果因为服务器故障没能返回答案，这一次不会计入额度，可以直接重试。如果知识库里完全没有可用于回答的资料，这一次也不计入额度。

回答等待较久：一次提问需要先检索资料再整理回答，通常几秒内返回。如果长时间没有反应并提示超时，回答有可能已经写好，可以退出这次会话再重新进入查看。

问答历史：每次对话都会保存，可以在个人中心的「问答历史」里找回，点击继续之前的对话。

需要注意：知识问答的答案来自平台知识库，仅供参考。涉及报名截止时间、活动安排、成绩与学籍等重要事项，请以小程序内的正式页面公告和学院通知为准。

必须登录才能使用知识问答。未登录时会提示先登录。

常见问法：知识问答是什么？书院助手是什么？智能问答怎么用？可以问什么？每天能问几次？次数用完了怎么办？为什么答不上来？为什么说没有找到相关资料？问答历史在哪里看？
